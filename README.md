# It's

Interactive Terminal's Selector

## ⚠️ WORK IN PROGRESS ⚠️

`its` is an upcoming fast, CLI-oriented selection tool written in Rust. 
It aims to be a dedicated, highly ergonomic picker for Unix-like environments, focusing strictly on selection workflows rather than pure fuzzy-finding.

This crate is currently a placeholder to reserve the name while the core architecture is being built. 

See the advancement of the project on [GitHub](https://github.com/Oignontom8283/its)!

> *Pipe your list, pick your item, and **it's** done.*
